# 대본·노트 작성 규칙

대사는 덱 스펙의 `script`(대사)와 `cues`(연출)에 쓰고, 생성기가 **대본 md**와 **pptx 노트** 두 곳에 넣는다.

## 대사(`script`) 쓰는 법

**목표: 대본만 읽어도 지금 화면이 어디인지 알 수 있어야 한다.**

- **화면 순서를 따라 말한다.** 슬라이드의 위→아래, 왼쪽→오른쪽 순서와 대사 순서를 맞춘다.
- **화면을 가리키는 말을 넣는다.** "두 코드를 보시죠", "왼쪽은 ~, 오른쪽은 ~", "아래 블록이 그 단계입니다", "실행 결과를 보시면".
- **존댓말, 짧은 문장.** 한 줄 = 한 호흡. 슬라이드당 4~8줄.
- **질문 뒤에는 `(5~8초 기다린다 — 채팅)`** 을 별도 줄로 넣는다. 덱 전체에서 2~3곳. 온라인이라 답하는 방법("채팅에 숫자만 써주세요")을 같이 말한다.
- **퀴즈**: 문제 슬라이드 `script`는 문제 읽기 + `(20~30초 기다린 뒤 넘긴다)`, 정답 슬라이드 `answerScript`는 "정답은 ○입니다" + **보충 설명 3~5문장**(동작 원리, 관련 클래스·개념, 실무에서의 의미). 이유는 앞 슬라이드 내용을 다시 가리키며 말한다.
- **강의 밖 보충** 슬라이드는 첫 줄에서 "강의에는 없는 내용을 보충하겠습니다"처럼 먼저 밝힌다.
- **화면에 없는 보충 설명**(예: "원리는 세 단계입니다")은 대사에만 넣어도 된다. 화면은 간결하게, 설명은 대사로.
- **인용문은 요약하지 않고 그대로 읽는다.** 대사에 `(인용 읽기)`라고 표시하고 cues에 "그대로 읽으세요".
- 강조할 말은 `**굵게**` — 대본 md에서 굵게 보이고, 노트에서는 표시가 빠진다.
- 코드·식별자는 `` `백틱` `` — 말할 때는 그대로 읽는다.
- **다음 슬라이드로 가는 다리 문장**으로 끝나면 좋다. ("예외도 컴파일 오류도 나지 않는다" → 실무 슬라이드)
- 실무 사례는 **겪은 일로** 말한다 ("저는 이 문장을 실무에서 그대로 만났습니다"). 회사 이름·클래스명·경로는 말하지 않는다.

## 연출(`cues`) 쓰는 법

- 발표자에게 하는 지시다. 청중에게 하는 말을 넣지 않는다.
- 쓸 것: 멈출 곳("한 박자 쉬세요"), 기다릴 곳("반드시 3초"), 무게 둘 곳, 그대로 읽을 곳, 데모 준비, 금지 사항(⚠️ 회사 코드 금지), 이 슬라이드가 다음과 이어지는 지점.
- 1~3개. 하나면 대본에 `**강조** — 문장` 한 줄로, 여럿이면 목록으로 출력된다.

## 시간(`time`)

- 슬라이드당 0:20~1:10. 목차·정리·정답은 짧게(0:30), 핵심·실무는 길게(1:00~1:10).
- **상한 15분.** 초안은 13분 안팎으로 잡아 보충 요청 여유를 둔다. 빌드 시 합계와 누적이 자동 계산된다.
- `time` 은 대사 길이에 맞춘다(대략 1분 = 대사 5~6줄). 시간 숫자만 줄이고 대사를 그대로 두지 않는다.

## 생성 결과 — 대본 md

```
# 발표 대본 — {meta.title}

> 대상 파일: `{pptx}` (**N장**)
> 목표 러닝타임: **{meta.runtime}** (합계 m:ss, 10~15분 범위, 질문 여유 포함)
> 모든 내용은 강의자료 PDF({meta.scope}) 범위 안에서만 구성했습니다.

## 시간 배분
| # | 슬라이드 | 시간 | 누적 |      ← 핵심·실무·데모 태그는 굵게
> 밀리면 {meta.compress}

## N. {label} · 0:50 【tag】
> 대사 한 줄
> 대사 한 줄

**강조** — 연출 한 줄          (또는 목록)

## 리허설 체크리스트           ← rehearsal
```

## 생성 결과 — pptx 노트 (발표자 보기)

```
[3/14 · 0:50 · 누적 2:30] 【핵심】

대사 한 줄
대사 한 줄

── 연출 ──
· 연출 한 줄
```

## 리허설 체크리스트(`rehearsal`)에 넣을 것

- 타이머로 전체 1회 측정 → 목표 시간 안인지
- 질문 후 기다리기(5~8초) 위치를 실제로 세어보기 (슬라이드 번호 명시)
- 퀴즈 2문제 각각 20~30초 기다리는 연습 (넘기는 타이밍)
- 실무 슬라이드는 슬라이드 안 보고 말로 되는지
- 회사 코드·클래스명·경로가 화면이나 말에 안 나오는지
- 발표 PC에 Pretendard 설치 확인
- 디스코드 화면공유: 슬라이드쇼 창만 공유, 발표자 보기 위치 확인
