# 스타일 버전 1 (v1) — 토스 블루

> **고정일 2026-10-04.** 스프링 입문 발표(사용자 피드백 3회 반영)로 확정한 규격.
> 덱 스펙에서 `"meta": { "style": "v1" }` 로 고른다(생략해도 v1).
> 표본: [examples/spring-intro.deck.json](../../examples/spring-intro.deck.json) — 빌드하면 `examples/out/` 에 생성(21장, git 제외). 실제 최종본은 `스프링입문/발표/`.

코드상의 단일 원본은 `scripts/styles/v1.js`다. 이 문서와 값이 어긋나면 **v1.js가 우선**이고, 이 문서를 고친다.
v1 을 크게 바꿔야 하는 요청(색 체계·폰트·레이아웃 교체)은 v1 을 고치지 않고 **새 버전(v2)** 으로 만든다 — [버전 목록](README.md).

## 콘셉트

- **토스 UI 톤**: 흰 배경, 강조색은 **Signal Blue 하나**, 나머지는 회색 단계로 위계를 나눈다.
- **어두운 슬라이드는 쓰지 않는다.** 강조는 큰 파란 카드(Signal Blue 면 + 흰 글씨)로 한다.
- 코드 블록만 어둡다 — IntelliJ Darcula 색을 그대로 재현한다.

## 색

기준 팔레트(사용자 제공 이미지)에서 **첫 번째 조합(Signal Blue / Porcelain)** 을 기본으로 쓴다.

| 역할 | 값 | 이름 | 쓰는 곳 |
|---|---|---|---|
| 배경 | `FFFFFF` | White | 모든 슬라이드 |
| 강조 | `0057FF` | Signal Blue | 제목 강조 구절, 단원 번호, 강조 불릿, 태그 글씨, 파란 카드 면 |
| 강조 틴트 | `EBF2FF` | Signal Blue 10% | 퀴즈 유형 칩 배경 |
| 본문 | `23262F` | Graphite | 제목·본문 텍스트 |
| 보조 | `6B7280` | (회색) | 소제목, 캡션, 카드 설명 — 흰 배경 대비 4.8:1 |
| 카드 면 | `F8F7F4` | Porcelain | 카드, 결론 박스, 퀴즈 줄 |
| 코드 배경 | `23262F` | Graphite | 코드 블록 |
| 경고 | `FF4696` | Dragonfruit | 함정·주의 한정. 대비 3.2:1이라 **18pt 이상 굵은 글씨에만**, 덱당 1~2회 |

- 팔레트의 나머지 색(Ultra Violet, Lime Spark, Emerald Ink, Butter Yellow, Royal Iris 등)은 **기본적으로 쓰지 않는다.** 필요해지면 이 표에 역할을 정해 추가한다.
- 한 슬라이드 안에서 파란색은 **한 덩어리**만 눈에 띄게 한다(제목 강조 구절 + 강조 불릿 1개 정도).

## 글꼴

| 용도 | 글꼴 |
|---|---|
| 제목·본문 | **Pretendard** (테마 글꼴에도 지정 — PowerPoint에서 새로 입력하는 글자도 Pretendard) |
| 코드 | Consolas (코드 안 한글 주석은 Pretendard로 표시) |

> 발표 PC에 Pretendard가 없으면 PowerPoint가 대체 글꼴로 그리면서 **줄이 잘리거나 겹친다.** 발표 전 반드시 확인.

## 그리드 (16:9 와이드, 13.33 × 7.5in)

- 좌우 여백 0.75in, 콘텐츠 폭 11.83in
- 소제목 y 0.5 · 제목 y 0.85 · 본문 시작 y 1.95 · 본문 끝 y 6.75
- 블록 간격 0.3in, 카드 라운드 0.12in, 코드 블록 안쪽 여백 0.2in
- 슬라이드 번호: 오른쪽 아래(레이아웃에 포함, 표지 제외)
- 제목은 **항상 왼쪽 정렬, 같은 위치**. 본문 문단도 왼쪽 정렬(가운데 정렬 금지)

## 레이아웃(슬라이드 마스터)

| 이름 | 제목 플레이스홀더 | 쓰는 유형 |
|---|---|---|
| `STUDY_COVER` | y 1.0, 40pt | cover |
| `STUDY_CONTENT` | y 0.85, 32pt | 대부분 |
| `STUDY_STATEMENT` | 화면 중앙, 40pt | statement |
| `STUDY_PRINCIPLE` | 왼쪽 열, 36pt | principle |
| `STUDY_QUIZ` | y 0.95, 30pt, 2줄 | quiz-item (문제·정답 두 장이 같은 배치) |

모든 제목이 플레이스홀더에 들어가므로 PowerPoint 개요 보기·발표자 보기에서 제목이 정상 표시된다.

## 하지 않는 것

- 어두운 배경 슬라이드
- 제목 아래 밑줄·장식선, 슬라이드 가장자리 색 띠, 카드 한쪽 테두리 강조
- 가운데 정렬 본문
- 글자 크기 최소치(본문 14 / 캡션 12 / 코드 14) 아래로 줄이기
- 코드 블록 13줄 이상 (온라인 규칙: 블록당 12줄 이하)
- 슬라이드 안에 대사 텍스트 넣기 — 대사는 노트와 대본 md에만
